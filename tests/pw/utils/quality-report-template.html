How to read this

  • Passed — normal green tests.
  • Known-defect guards — test.fail() tests pinning a filed defect. They fail on purpose while the bug is open, so they are not a regression. Each names its issue in a comment and asserts on its own final assertion, never on a precondition.
  • Guards now passing — the bug appears fixed. This is how a closed defect announces itself without anyone re-testing by hand.
  • Failed — the only bucket that gates a run.
  • Skipped — declined with a recorded reason, never a silent pass.

What the suite deliberately does not cover, and why, is recorded in the QA coverage ledger, which is kept out of this repository because it details defects that are still open.
